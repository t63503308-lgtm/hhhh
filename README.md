## 2. วิธีการติดตั้งและเริ่มใช้งานระบบ (Installation & How to Run)

### วิธีที่ 1: เปิดใช้งานโดยตรง (Offline Plug & Play - แนะนำ)
1. ดับเบิลคลิกที่ไฟล์ `index.html` หรือรันไฟล์ `RUN_LOCAL.bat`
2. ระบบจะเปิดบนเว็บเบราว์เซอร์เริ่มต้นทันที (รองรับ Google Chrome, Microsoft Edge, Firefox, Safari)
3. ระบบถูกออกแบบให้ **Zero-Dependency** และมีไลบรารี `chart.umd.js` อยู่ภายในโฟลเดอร์ `js/` เรียบร้อยแล้ว ทำให้ใช้งานแบบ **Offline ได้ 100%** โดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต

### วิธีที่ 2: รันผ่าน Local Web Server (แผนสำรอง)
หากต้องการรันผ่าน Web Server:
```bash
# กรณีมี Python
python -m http.server 8080

# กรณีมี Node.js
npx serve .
```
แล้วเปิดเบราว์เซอร์ไปที่: `http://localhost:8080`

## 5. รายการไฟล์ในระบบส่งมอบ (Deliverables Package)

- `index.html` : หน้าเว็บแดชบอร์ดหลักของระบบ
- `RUN_LOCAL.bat` : สคริปต์ดับเบิลคลิกเพื่อเปิดระบบทันที
- สไตล์และ Print Stylesheet ฝังอยู่ภายใน `<style>` ใน `index.html`
- `js/app.js` : ตัวควบคุมระบบ (Authentication, Interactive Filters, Chart Rendering, Table Sorting/Paging, CSV Export)
- `js/library_data.js` : ข้อมูลที่ทำความสะอาดแล้ว ข้อมูลตรวจสอบข้อผิดพลาด และข้อมูลตั้งต้น
- `js/chart.umd.js` : ไลบรารี Chart.js เวอร์ชัน UMD สำหรับการทำงานแบบ 100% Offline
- `library_book_loans_dirty_150.csv` : ชุดข้อมูลตั้งต้นตามโจทย์ (150 แถว)
- `library_book_loans_clean_149.csv` : ชุดข้อมูลที่จัดเตรียมและทำความสะอาดแล้ว (149 แถว)
- `data_dictionary.csv` : พจนานุกรมข้อมูลระบุชื่อฟิลด์ ชนิด หน่วย ตัวอย่าง และกฎเกณฑ์
- `data_cleaning_process.md` : บันทึกขั้นตอนการเตรียมข้อมูลและตรวจสอบคุณภาพอย่างละเอียด
- `user_guide_infographic.md` : คู่มือการใช้งานระบบฉบับย่อ
- `README.md` : เอกสารฉบับนี้
